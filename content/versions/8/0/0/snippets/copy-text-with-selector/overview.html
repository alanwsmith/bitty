[! filter markdown|safe !] - The `b.copy(selector)` method copies text from the element with the given selector. - The `.value` is copied if it exists. Otherwise, the `.innerHTML` is copied. - If you want feedback (e.g. changing "Copy Text" to "Copied" for a short interval), you can [roll your own](/versions/8/0/0/snippets/copy-text-with-selector-plus-message/) or use the [b.quickCopy](/versions/8/0/0/snippets/copy-with-quick-copy/) method.
